Sissy Jewelry ✨ - GDGoC Final Project

Sebuah katalog perhiasan eksklusif berbasis web yang interaktif dan responsif. Proyek ini dibuat sebagai Final Project untuk kelas mingguan Web Development 2.0 - Google Developer Groups On Campus (GDGoC) UIN Syarif Hidayatullah Jakarta.

🌟 Fitur Utama 
Proyek ini dibangun untuk memenuhi kriteria fungsionalitas dan interaktivitas, meliputi:
- Responsive Layout: Menggunakan sistem Grid dan Flexbox agar tampilan tetap rapi dan optimal baik di layar desktop maupun perangkat mobile.
- Data Fetching: Katalog perhiasan di-load secara dinamis menggunakan `Fetch API` publik dari [Fake Store API] (https://fakestoreapi.com/).
- Dynamic Interactivity:
  - 🌓 Dark/Light Mode: Pengalaman pengguna yang nyaman dengan tombol toggle tema.
  - 🔍 Real-time Search: Fitur filter pencarian perhiasan yang langsung bereaksi terhadap input ketikan pengguna.
  - 🛒 Cart Counter: Simulasi penambahan barang ke keranjang belanja (Add to Cart).

🛠️ Tech Stack
Proyek ini murni dibangun menggunakan teknologi Frontend berikut:
- HTML (Semantik dan terstruktur)
- Tailwind CSS (Melalui CDN untuk styling dan responsiveness)
- Vanilla JavaScript (Untuk fetching data dan logika interaktif)
